# DACH-LLMRec publication literature matrix

Search date: 2026-07-31. This is a screening-grade matrix, not a systematic review.

| Work | Type | What it contributes | Closest relevance to DACH-LLMRec | Limitation / opening for this project |
|---|---|---|---|---|
| Zhang et al., CoLLM, IEEE TKDE 2025, arXiv:2310.19488, DOI:10.1109/TKDE.2025.3540912 | LLM4Rec method | Maps collaborative embeddings from conventional recommenders into the LLM token embedding space. | Shows that collaborative signals should not be replaced by text-only LLM prompting. | Not food-specific; not focused on health constraints, long-term diet trajectory, or faithful nutrition explanations. |
| Kim et al., Lost in Sequence / LLM-SRec, KDD 2025, arXiv:2502.13909 | Sequential LLM4Rec diagnosis and method | Shows that existing LLM4Rec methods often fail to capture user interaction sequences; distills CF-SRec representations into LLMs through lightweight MLPs. | Directly motivates adding sequence-aware knowledge distillation to DACH-LLMRec. | General sequential recommendation, not health-aware food recommendation; no nutrient constraint trajectory. |
| Wei et al., LLMRec, WSDM 2024, arXiv:2311.00423, DOI:10.1145/3616855.3635853 | LLM graph augmentation | Uses LLMs to augment user-item interaction edges, item attributes, and user profiles. | Useful precedent for LLM-based data augmentation and graph-enhanced recommendation. | Benchmarks are entertainment domains; no hard nutrition constraints or medical/health evidence boundary. |
| Zhang et al., DualAgent-Rec, WWW Companion 2026, arXiv:2601.19121, DOI:10.1145/3774905.3795728 | Constraint-compliant multi-agent optimization | Uses an LLM coordinator to allocate effort between exploitation and exploration agents under hard constraints. | Supports treating LLM as optimizer/orchestrator rather than item scorer. | E-commerce constraints, not nutrition constraints; no sequential diet state or nutrient balance. |
| Lechiakh et al., Towards long-term depolarized interactive recommendations, Information Processing & Management 2024, DOI:10.1016/j.ipm.2024.103833 | Constrained RL recommendation | Models long-term interactive recommendation with DQN variants and category-level constraints. | Provides the closest template for long-term constrained recommendation. | Optimizes depolarization, not dietary balance; not LLM-integrated and not food-domain specific. |
| Sani et al., FIRE, arXiv:2508.05225 | Faithful explanation | Grounds recommendation explanations in model decision logic using feature attribution and LLM generation. | Motivates evidence-grounded DACH explanations and explanation fidelity metrics. | General review-domain explanation; does not handle nutrition constraints or diet-specific evidence. |
| Zhang et al., MOPI-HFRS, KDD 2025, arXiv:2412.08847, DOI:10.1145/3690624.3709382 | Health-aware food recommendation | Builds health-aware food recommendation benchmarks, graph structure learning, Pareto optimization, and LLM-enhanced interpretation. | The strongest direct competitor for any "health-aware food recommendation + LLM explanation" claim. | Appears focused on static top-k health-aware food recommendation; this project can differentiate on sequential meal trajectory, hard constraints, and explanation faithfulness. |
| Khamesian et al., NutriGen, EMBC 2025 / arXiv:2502.20601, DOI:10.1109/EMBC58623.2025.11253879 | LLM meal-plan generation | Generates personalized meal plans aligned with preferences and constraints using LLM prompting and nutrition databases. | Useful practical baseline for meal-plan generation. | Generation-centric; weaker on collaborative recommendation, top-k ranking, and faithful model-grounded explanation. |
| Papastratis et al., Scientific Reports 2024, DOI:10.1038/s41598-024-65438-x | Deep generative nutrition planning | Uses deep generative modeling and ChatGPT with nutrition-guideline losses for meal planning. | Supports nutrient-guideline loss design. | Meal-plan generation rather than recommender-system sequence policy; limited collaborative signal. |
| Yang et al., ChatDiet, Smart Health 2024, DOI:10.1016/j.smhl.2024.100465 | Conversational nutrition recommendation | LLM-augmented chatbot with personal and population models for nutrition-oriented recommendations. | Motivates practical conversational interface and personalization. | Case-study style evidence; explanation quality and constraint compliance need stronger model-grounding. |
| Marin et al., Recipe1M+, IEEE TPAMI 2019, DOI:10.1109/TPAMI.2019.2927476 | Dataset / multimodal food representation | Large-scale recipe-image dataset and cross-modal embeddings. | Provides candidate external item-side data for recipe semantics and multimodal features. | Does not include longitudinal user-health outcomes; nutrition coverage is partial. |
| Food.com Recipes and Interactions, Kaggle | Dataset | Food.com recipes and long-term user interactions/reviews. | Practical external dataset for sequential user-recipe interactions. | Health labels and nutrient constraints need enrichment and validation. |
